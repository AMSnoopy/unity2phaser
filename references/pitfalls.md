# 高频坑与自查清单

来自真实 Unity→Phaser 转换中反复出现的问题。**每完成一个阶段，把本清单过一遍**；验收阶段逐条核对。每条都写明"症状→原因→正确做法"。

## 坐标与布局

1. **画面整体偏移/镜像**：Unity y 向上、Phaser y 向下。症状：整个布局上下颠倒或元素错位。原因：换算时忘了取反 y，或取反了两次。做法：选一个带旋转/非中心 pivot 的对象当对照，全程只翻转一次（见 mapping.md §3）。
2. **用 UI 公式算世界坐标（或反了）**：CanvasScaler 参考分辨率 ≠ 摄像机视野。世界空间用 `orthographicSize × 2 × PPU`；UI 用参考分辨率 + anchors/pivot。两套公式出现在同一个场景时分开算。
3. **Prefab 覆盖值丢了**：场景里 Prefab 实例的属性 override 覆盖 Prefab 模板值。只读 .prefab 文件会拿错。做法：以场景 YAML 里实例的序列化值为准，模板值只做缺省。
4. **stretch 锚点当固定尺寸**：anchorMin≠anchorMax 时 sizeDelta 是到锚点的边距，不是宽高。解析时按锚点区间换算。
5. **图被拉伸**：原图有 pivot/切片（9-slice border）信息没迁移。症状：按钮/面板圆角变形。做法：9-slice 用 Phaser `NineSlice` 对象或手动三段式；`setDisplaySize` 后保存基准 scale（见下）。
   变体（真实案例）：**纹理长宽比 ≠ prefab rect 长宽比时以 rect 为准**——Unity 本来就是把纹理压扁进 rect 显示的（319×388 贴图压进 139.2×186.24），你按纹理比例显示反而是错的。

## 缩放与动画

6. **`setScale(1)` 灾难**：`setDisplaySize` 改的是 scaleX/scaleY。之后动画写 `setScale(1)` 会让纹理瞬间撑到原始像素尺寸。做法：定尺寸后存 `baseScaleX/baseScaleY`，动画用 `baseScale × k`。
7. **DOTween 时序拍扁**：`Append`（顺序）、`Join`（与上一段并行）、`Insert`（绝对时刻插入）在 Phaser 里要用 timeline 显式重建重叠/前后关系，不能全变成顺序 delayedCall。**秒→毫秒要 ×1000**。
8. **逐帧动画变匀速 tween**：.anim 里的 PPtrCurves 是"换图帧序列"，不是数值补间。按帧时间（sampleRate / m_Time）建成 spritesheet 动画播放；曲线动画才用 tween，且注意关键帧切线（缓入缓出），不要拉直。
9. **Animator 循环丢失**：循环看 Animator 状态与 clip 的 LoopTime，不是 clip 文件本身。状态转换条件（SetTrigger/bool）要在 JS 里显式建模。
10. **教学/庆祝被剪短**：为了"看着利索"把原版 1.5 秒的入场教学或成功庆祝压成 0.3 秒，是**保真度破坏**。原版节奏（尤其面向儿童的数数、旁白、完整尾段）必须保留完整时长。

## 交互

11. **拖动丢抓取偏移**：手指按下点不在对象中心时，对象会"跳到手指下"。做法：pointerdown 时记 `offset = obj中心 − pointer位置`，drag 全程保持。
12. **点击穿透/点错层**：Phaser `input.topOnly` 默认 true 但按 depth 排序；原 Unity 的 EventSystem 屏蔽逻辑（raycaster 目标、blocksRaycasts）要检查——不可交互状态要 `disableInteractive()`，而不是只改透明度。**可见性与可交互性是两个独立状态**：隐藏/禁用对象要同时 `setVisible(false)` + `disableInteractive()`，"看不见但能点"与"看得见但不能点"都是高频 bug，验收时分开核对。
13. **CSS 坐标当游戏坐标**：pointer 事件给出的是画布 CSS 像素。FIT 缩放后要按 `画布实际渲染尺寸 / 设计分辨率` 比例换算回游戏坐标（Phaser 的 pointer 已换算，手写 DOM 事件时要自己算）。
14. **滑动改成拖槽/静态点选**：原版是"连续滑动划过/移动拾取"的定义性玩法，实现成"点一下选择"就是换了玩法，不算等价转换。手势类型必须与原版一致。

## 音频

15. **声音不出**：浏览器要求首次真实用户手势后才能出声。必须在首个 pointerdown 解锁 AudioContext；解锁前触发的提示音要排队而不是丢弃。
16. **提示打断旁白**：原版音效/旁白有队列与优先级（如教学中旁白没说完不接受输入）。转换后音效全并行就是错的。做法：实现一个按通道（BGM/语音/音效）的队列管理器，保留原版的打断/排队关系。
17. **尾段被截断**：成功/结束的声音+动画完整播完才算"完成"，不要用固定 `setTimeout(800)` 假装等完。静音调试时队列时序仍要走完。
18. **重开 BGM 叠加**：每次重开都 new 一个音频实例且没停旧的 → 双声污染。BGM 归游戏级管理器管，重开不重启，退出才销毁。

## 生命周期

19. **重开残留**：旧 tween/delayedCall/监听器在新一局触发。规则：重开 = 完整销毁（scene.shutdown 里清干净）再重建；必测"玩到一半重开两次"。
20. **async 回调穿越重开**：`delayedCall`/`fetch` 的回调落在新一局对象上造成幽灵状态。做法：回调先检查"本局已结束"标志；Scene 销毁时置位。
21. **暂停不彻底**：只 `scene.pause` 但 tween/音频还在跑。暂停要覆盖：场景更新、tween、计时器、音频、输入。恢复时只解除暂停原因集合为空的情况（多原因暂停：手动+视口变化，要全部解除才恢复）。
22. **Resources.Load 动态路径漏资源**：脚本里 `"prefab_" + level` 这类拼接路径，静态扫描找不到。做法：追到调用点，展开成完整静态清单，把所有候选路径的资源都迁移；展开不了（纯运行时计算）就登记为待确认。

## 资源

23. **AI 重绘素材**：绝对禁止用生成图替代已有素材——原版素材就是验收基准。只有确实缺失的素材才允许生成替代并登记缺口。
24. **图集切图错位**：spriteMode=Multiple 的 .meta 里有每个 sprite 的 rect/pivot/border，生成 atlas JSON 时逐条核对，抽一张对照原版截图验证。
25. **TMP/字体缺字**：原字体没带全中文字形，或 fallback 没迁移，症状是方块字。做法：复制原字体文件 + 配好 fallback 链；文案里的每个字符确认能渲染。
26. **大文件拖慢加载**：原项目里的未压缩 png/长 wav 全量搬进网页会让首屏卡住。做法：先原样迁移保证正确，加载时间成为问题时才做**有损但视觉/听觉等价**的压缩，并在 asset-map 登记"源文件→输出文件+处理方式"。

## 工程与流程

27. **做一半就停**：单次会话输出有长度限制，不允许"做到哪算哪"。做法：严格按阶段推进，每阶段结束输出阶段报告并更新 progress.md；中断后新会话从 progress.md 恢复，而不是从头再来或假装完成。
28. **静态通过 ≠ 真的能玩**：verify 脚本全绿只说明文件齐了。必须本地 serve 起来真实玩一遍：完整通关一次 + 中途失败一次 + 重开一次。
29. **范围蔓延**：转换任务自动变成重新设计。增强只在验收通过后进行；改动已认可体验前先给前后对照。
30. **3D/重度依赖硬转**：遇到 3D 模型、自定义 shader、骨骼动画（Spine）重度依赖、原生插件时，如实说明网页支持方式与限制，能降级实现就降级并登记，不能降级的明确说"无法等价转换"，不冒充完成。
31. **index.html 漏引场景脚本**（真实案例）：骨架建好后忘了把 `src/scenes/*.js` 加进 index.html——页面无任何报错，但场景方法从未挂载，游戏永远黑屏/空转。症状：`typeof scene.preload === 'function'` 为 false。做法：阶段 2 出口必须逐一核对 script 标签与 src 文件一一对应。
32. **场景启动竞态**（真实案例）：`new Phaser.Game({scene:[...]})` 在场景方法赋值之前执行（脚本顺序/异步定义），场景以"无 preload/create"状态启动，加载器 0 文件、场景卡在 CREATED。做法：**创建 Phaser.Game 必须延迟到 window load 之后**（或先 add 场景再 start），模板见 workflow 阶段 2。
33. **代际标记捕获时序**（真实案例）：`var gen = S.gen` 写在了会再 `gen++` 的清理函数之前，异步回调的代际校验恒为 false，关卡数据永远不加载（且无报错）。做法：**捕获代际号必须放在最后一次 gen++ 之后**；审查所有"++ 后捕获"的顺序。
34. **后台标签动画冻结（测试环境）**：浏览器对被遮挡/失焦的窗口暂停 rAF（可降到 0 帧），Phaser 动画、tween、延迟回调全部停滞——这不是游戏 bug。自动化试玩时若画面"卡住"，先测 `requestAnimationFrame` 是否还在走（见 acceptance.md），并把窗口置于前台再测。
35. **异步加载的代际保护双刃剑**：给 fetch/加载回调加代际校验是对的，但捕获时机错了会把正常流程也拦死（见 33）。校验失败时最好留一条 debug 日志（如 `console.warn('[gen] stale callback dropped')`），否则这种"静默不加载"极难排查。
36. **UI 子元素标签偏移目测化**（真实案例）：字母标签整体偏上 30px。原因：prefab 里 TMP 标签 `anchoredPosition=(0,-18.9)`（UI y+ 向上 = 屏幕向下 18.9），换算时方向搞反还加了目测补偿 `-12`，双重错误叠加。做法：**子元素偏移一律用公式算（mapping.md §3 步骤 3），禁止目测**；换算后对照原版截图检查"文字是否在目标图形内居中"这类局部关系，整体布局对了不代表子元素偏移对了。
37. **裁剪贴图改变显示尺寸**（真实案例）：蜜蜂显示比原版小 8% 且位置偏移。原因：trim 掉透明边后，裁剪图 ≠ Unity sprite——Unity 显示的是 .meta 里的 sprite rect（大画布中的子矩形，如 2048 画布里 336×359），裁剪图比 rect 还大（363×375，含 rect 外内容）。做法：裁剪图的显示尺寸 = rect 显示尺寸 × (裁剪像素/rect 像素)，本例 157.92×(363/336)=171。**凡做过 trim，必须回读 meta rect 重新推导显示尺寸**，并把 rect 在画布中的偏移用于对齐。
38. **共享管理器的间接资源引用**（真实案例）：GUID 闭包与 Resources 调用扫描全部干净，结论"声音来源齐全"，但游戏没有背景音乐。原因：脚本调用平台层管理器接口（如 `AudioManager.AddMusic("bgm1")`），管理器类与其"名称→资源路径"映射在共享/平台层目录，不在游戏目录内，静态闭包追不到。做法：凡脚本调用 XxxManager/XxxLoader 类接口，**先找该管理器的资源注册表或路径映射**，沿调用参数的分组/标识追到真实文件；追不到就显式登记缺失（缺哪个标识、影响、需用户提供什么）——扫描结果为空 ≠ 来源齐全。
39. **运动中目标的命中判定**：原版允许点击漂移/移动中的对象时，容器上声明的 hitArea 是固定矩形，不会跟随 tween 后的实际视觉位置，出现"看着在这、点了没反应"。做法：命中以对象**实时位置**为准（hitArea 按 home+当前偏移计算，或 pointerdown 用实时坐标判定），并保留原版的可点状态门控（tween 中可点/不可点按原版）。截图对照发现不了这类 bug——**必须真实点击运动中的对象**验证。
